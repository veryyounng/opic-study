# My OPIc Trainer

영수증 콘셉트의 모바일 OPIc 말하기 연습 페이지입니다.

## 실행

`index.html`을 브라우저에서 열어 사용할 수 있습니다. 마이크 녹음 기능은 브라우저 보안 정책에 따라 HTTPS 또는 localhost에서 열어야 동작할 수 있습니다.

## 주요 파일

- `index.html`: 연습 화면과 버튼 구성
- `style.css`: 영수증 스타일과 모바일 화면 배치
- `app.js`: 질문, 타이머, 음성 재생, 녹음 동작
- `스티커/`: 화면 장식 이미지
- `deliverables/`: 아이콘과 디자인 참고 산출물

## QA 스모크 테스트

질문 표시, 주제·유형 필터, 영어 질문 열기, 즐겨찾기, 타이머 동작을 브라우저에서 확인합니다.

```bash
npm install
npx playwright install chromium
npm run qa
```

마이크 녹음은 브라우저 권한과 기기 환경에 영향을 받아 이 기본 테스트에는 포함하지 않았습니다.

## 연습 데이터

연습 시작·완료, 질문과 주제, 힌트 사용, 재시도, 간단한 자기평가를 브라우저 로컬 저장소에 기록합니다. 녹음 파일이나 답변 내용은 저장하지 않으며, `오늘 기록`에서 CSV를 내려받을 수 있습니다. 다른 브라우저나 기기와 자동으로 공유되지는 않습니다.
