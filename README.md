# My OPIc Trainer

영수증 콘셉트의 모바일 OPIc 말하기 연습 페이지입니다.

## 실행

`index.html`을 브라우저에서 열어 사용할 수 있습니다. 마이크 녹음 기능은 브라우저 보안 정책에 따라 HTTPS 또는 localhost에서 열어야 동작할 수 있습니다.

## 주요 파일

- `index.html`: 연습 화면과 버튼 구성
- `style.css`: 영수증 스타일과 모바일 화면 배치
- `app.js`: 질문, 타이머, 음성 재생, 녹음 동작
- `스티커/`: 화면 장식 이미지
- `deliverables/`: 아이콘과 디자인 참고 산출물
